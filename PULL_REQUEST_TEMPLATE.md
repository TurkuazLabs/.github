Bagimli Oldugu Katman: Tool

## Degisiklik Ozeti / Change Summary

Bu pull request neyi degistiriyor? / What does this pull request change?

## Neden Gerekli? / Why Is It Needed?

Degisikligin gerekcesini aciklayin. / Explain why this change is needed.

## Test / Testing

Degisikligin nasil test edildigini belirtin. / Describe how the change was tested.

## Kontrol Listesi / Checklist

- [ ] Degisiklik tek bir amaca odakli.
- [ ] Ilgisiz dosyalar degistirilmedi.
- [ ] Mevcut testler calistirildi veya test gerekmiyor.
- [ ] Yeni davranis varsa dokumantasyon guncellendi.
- [ ] Hassas veri, parola veya API anahtari eklenmedi.
- [ ] Change is focused on one purpose.
- [ ] No unrelated files were changed.
- [ ] Tests were run or are not applicable.
- [ ] Documentation was updated when needed.
- [ ] No secrets, passwords, or API keys were added.
