# Security Policy / Guvenlik Politikasi

## Turkce

Bir Turkuaz Labs projesinde guvenlik acigi bulduysaniz, lutfen herkese acik bir GitHub issue olusturmayin.

Guvenlik bildirimlerini **security@turkuazlabs.com** adresine gonderin.

Bildirimde mumkunse sunlari belirtin:

- Etkilenen proje ve surum
- Sorunun kisa aciklamasi
- Tekrar uretme adimlari
- Olasi etki
- Varsa ornek, log veya ekran goruntusu

Hassas bilgileri, parolalari, API anahtarlarini veya gercek kullanici verilerini herkese acik alanlarda paylasmayin.

## English

If you discover a security vulnerability in a Turkuaz Labs project, please do not open a public GitHub issue.

Send security reports to **security@turkuazlabs.com**.

Please include, when possible:

- Affected project and version
- Short description of the issue
- Reproduction steps
- Potential impact
- Relevant examples, logs, or screenshots

Do not publish passwords, API keys, private data, or other sensitive information in public issues.
